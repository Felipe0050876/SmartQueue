========================================================
  SmartQueue — BASE COMPARTIDA (Paso 0)
========================================================

Esto NO es el proyecto completo. Es solo el esqueleto base que
sube UNA persona a la rama "develop". Contiene los archivos que
todos comparten. Cada desarrollador agrega DESPUES sus archivos
en su propia rama.

--------------------------------------------------------
IMPORTANTE
--------------------------------------------------------
Esta base, por si sola, NO compila todavia. Es lo esperado:
faltan los modelos, controladores y vistas que cada dev pega
en su rama. El proyecto compila completo una vez que las 5
ramas se integran en "develop".

--------------------------------------------------------
COMO SUBIR ESTA BASE A GITHUB
--------------------------------------------------------
1. Crea un repositorio vacio en GitHub (sin README).
2. Abre una terminal dentro de esta carpeta y ejecuta:

   git init
   git branch -M main
   git remote add origin https://github.com/USUARIO/SmartQueue.git
   git add .
   git commit -m "Base del proyecto SmartQueue"
   git push -u origin main

   git checkout -b develop
   git push -u origin develop

3. Listo. Cada dev ya puede sacar su rama desde "develop".

(Los pasos completos y los comandos de cada dev estan en el
 documento "SmartQueue_Guia_Git.docx".)
